# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | `needs-info` | Awaiting more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Specified enough for an agent to implement independently |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will be closed without implementation |

When a skill names a triage role, use its tracker label from this table.
